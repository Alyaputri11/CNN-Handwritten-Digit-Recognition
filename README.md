# CNN Handwritten Digit Recognition

## Project Overview
This project implements a Convolutional Neural Network (CNN) to recognize handwritten digits using the MNIST dataset.

The model classifies handwritten digit images into ten categories, ranging from 0 to 9.

## Objectives
- Understand the basic concept of Convolutional Neural Networks.
- Implement CNN for image classification.
- Train a deep learning model using the MNIST dataset.
- Evaluate model performance using accuracy.

## Technologies Used
- Python
- TensorFlow
- Keras
- Google Colab
- MNIST Dataset

## CNN Architecture
The model consists of the following layers:
1. Convolutional Layer
2. Max Pooling Layer
3. Convolutional Layer
4. Max Pooling Layer
5. Flatten Layer
6. Dense Layer
7. Softmax Output Layer

## Dataset
The MNIST dataset contains handwritten digit images from 0 to 9.

Each image has a resolution of 28 × 28 pixels in grayscale.

## Expected Output
The trained CNN model predicts the handwritten digit from an input image and evaluates its classification accuracy.
